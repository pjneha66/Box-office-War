# Box Office War — Android APK

The game is wrapped with [Capacitor](https://capacitorjs.com) as a fully offline
Android app: every game asset is bundled inside the APK, no server needed.

## Rebuild the APK (after any game update)

```bash
# 1. toolchain (already installed on this Mac)
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
export ANDROID_HOME=/opt/homebrew/share/android-commandlinetools

# 2. refresh the web bundle (copies game files into www/, strips the SW registration)
node build-www.js

# 3. bump the app version (optional)
#    apk/android/app/build.gradle -> versionCode / versionName

# 4. build
cd android
./gradlew assembleRelease

# output: android/app/build/outputs/apk/release/app-release.apk
#         (also copied to dist/BoxOfficeWar-<version>.apk by the release step)
```

`adb install -r app-release.apk` installs over an existing copy **only if signed
with the same key**.

## Signing — DO NOT LOSE the keystore

- `signing/boxofficewar.keystore` (alias `bow`, password in `android/keystore.properties`)
- It is committed to the repo on purpose: the game's saves live in the app's
  local storage, and installing an update signed with a different key forces an
  uninstall first — which would wipe every save. If you ever make this repo
  public, move the keystore out and rotate it before publishing.
- For Play Store distribution you'd upload an **AAB** (`./gradlew bundleRelease`)
  with Play App Signing instead.

## Layout

- `build-www.js` — build step: repo game files → `www/` (gitignored), strips the
  service-worker registration (the APK serves assets locally; a cache-first SW
  would only risk stale builds).
- `make-assets.mjs` — regenerates `assets/` icon + splash sources from the
  game's `icon.svg` (needs repo-root `node_modules/sharp`).
- `android/` — standard Capacitor 8 Android project (committed; safe to delete
  and re-create with `npx cap add android`).
- Icons/splash live in `android/app/src/main/res/` (generated by
  `@capacitor/assets generate --android` from `assets/`).
